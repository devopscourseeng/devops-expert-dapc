# Session 5 slides

| File | What it is |
|---|---|
| [session-5-kickoff.pptx](session-5-kickoff.pptx) | The 17-slide trainer deck for Session 5, with speaker notes on every slide |
| [session-5-kickoff.pdf](session-5-kickoff.pdf) | The same slides as a PDF (no speaker notes) |

The slides in the PowerPoint file are pictures, so their text cannot be edited there. The speaker notes can be edited. The editable version of the deck is the Slides artifact in Claude. To change a slide, edit it there and export again.

Related files:

- `training/docs/setup-tools.md`: step-by-step instructions for the setup slide
- `training/session_5/three-ways/`: backup answers for the Three Ways activity, for participants who cannot use Claude
