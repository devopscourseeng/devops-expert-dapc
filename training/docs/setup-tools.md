# Set up your tools in five steps

Session 5 · Kickoff. You do the steps, Claude guides you.

**Goal:** by the end you have access to the course GitHub repository and the Jira project, and Claude is connected to both.

**Stuck?** Ask Claude to walk you through the step (for example: "I just got an email invitation to a GitHub repository, what do I do?") and tell the instructor early. If you finish first, help a neighbour.

> Menu names in GitHub, Jira and Claude change from time to time. If a button is not where this guide says, describe what you see to Claude and ask where to click.

---

## Step 1. Accept the GitHub invitation to the course repository

Repository: https://github.com/devopscourseeng/devops-expert-dapc

1. Open the email from GitHub with the subject "You have been invited to collaborate on devopscourseeng/devops-expert-dapc". You can also go to the repository link above while signed in.
2. Click **View invitation**, then **Accept invitation**.
3. If you do not have a GitHub account, create a free one first at https://github.com/signup, then open the invitation again.
4. Turn on two-factor authentication if GitHub asks for it.

**Done when:** opening the repository shows you as a collaborator and you see the **Pull requests** tab.

## Step 2. Accept the Jira invitation to the SCRUM project

Project: https://devopscourseeng.atlassian.net/jira/software/projects/SCRUM/boards/1

1. Open the invitation email from Atlassian.
2. Click **Join** (or **Accept invite**) and sign in or create an Atlassian account with the same email the invitation was sent to.
3. Open the SCRUM board using the link above.

**Done when:** you can see the SCRUM board and its tickets.

## Step 3. Open Claude and sign in with your account

1. Go to https://claude.ai (or open the Claude desktop or mobile app).
2. Sign in with your account, or create one.
3. A Pro plan is required for the course. Tell the instructor if something is blocked.
4. Start a new chat and say hello to confirm it works.

**Done when:** you can send a message to Claude and get an answer.

## Step 4. Connect GitHub to Claude

1. In Claude, open **Settings** and go to **Connectors** (the name may differ slightly).
2. Find **GitHub** and click **Connect**.
3. Sign in to GitHub if asked and approve the access request.
4. When asked which repositories Claude can use, allow `devopscourseeng/devops-expert-dapc`.

**Done when:** GitHub appears as connected in Claude's settings. Step "Verify" on the next slide checks that Claude can read the repository.

## Step 5. Connect Jira to Claude

1. In the same **Connectors** page, find **Atlassian** or **Jira** and click **Connect**.
2. Sign in with your Atlassian account and approve the access request.
3. Choose the `devopscourseeng` site when asked.

**Done when:** Jira appears as connected in Claude's settings. Step "Verify" on the next slide checks that Claude can read the SCRUM tickets.
